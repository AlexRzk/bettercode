ชุดโครงการชุมชนที่สร้างขึ้นบน BetterCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ BetterCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-bettercode](https://github.com/awesome-bettercode/awesome-bettercode) และ [bettercode.cafe](https://bettercode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
